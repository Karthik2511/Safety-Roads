# 📜 Changelog

All notable changes to Safety Road.

## [1.0.0] - 2024-01-15

### Added

- ✅ Real-time pothole detection with YOLOv8
- ✅ React Native mobile app (iOS & Android)
- ✅ FastAPI backend with inference
- ✅ GPS-based interactive map
- ✅ Severity classification (High, Medium, Low)
- ✅ Local SQLite database
- ✅ Batch image processing
- ✅ Comprehensive API documentation
- ✅ Docker containerization
- ✅ Cross-platform compatibility

### Features

- **Detection**: Real-time YOLOv8 inference (87ms)
- **Mapping**: GPS-tagged locations with color-coded markers
- **Classification**: Automatic severity detection
- **Storage**: Local SQLite with optional cloud sync
- **Performance**: 92% accuracy on custom dataset
- **Scalability**: Batch processing support

## [0.9.0] - 2024-01-10

### Added (Beta)

- Initial MVP with core functionality
- YOLOv8 Nano model integration
- Basic React Native UI
- FastAPI backend setup
